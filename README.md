## Описание проекта
### Цель
- Проанализировать данные маркетплейса и определить уровень  product/market fit, а также значимые метрики и гипотезы.

### Задачи
- Задача 1: Оценить месячный retention в оформление заказа с помощью когортного анализа.
- Задача 2: Определить, существует ли product/market fit у этого маркетплейса.
- Задача 3: Определить 5 основных метрик, на которых продакту можно сконцентрироваться, чтобы максимизировать прибыль компании.
- Задача 4: Выбрать одну из 3 основных гипотез с помощью фреймворка ICE.
- Задача 5: Сформулировать нужные метрики, на которые гипотеза должна повлиять.


## Описание набора данных
Общедоступный набор данных о заказах, оформленных в бразильском интернет-магазине Olist Store. Набор данных содержит информацию о 100 000 заказов, оформленных с 2016 по 2018 год на различных бразильских торговых площадках. Он позволяет просматривать заказы по нескольким параметрам: от статуса заказа, цены, оплаты и доставки до местоположения клиента, характеристик товара и, наконец, отзывов покупателей. 

Это реальные коммерческие данные, они анонимизированы, а ссылки на компании и партнеров в тексте обзора заменены названиями великих домов из «Игры престолов».

### Контекст

Этот набор данных предоставлен компанией Olist, крупнейшим универмагом на бразильских рынках. Olist связывает малые предприятия со всей Бразилии с каналами сбыта. Эти продавцы могут продавать свою продукцию через магазин Olist и доставлять ее напрямую покупателям, используя логистических партнеров Olist.

Пример карточки товара на торговой площадке:

![Пример карточки товара](images/Example%20of%20a%20product%20listing%20on%20a%20marketplace.png)

После того, как покупатель приобретает товар в магазине Olist Store, продавец получает уведомление о необходимости выполнения заказа. После получения товара покупателем или наступления предполагаемой даты доставки, покупатель получает по электронной почте анкету удовлетворенности, где он может оставить отзыв о своей покупке и поделиться своими комментариями.

Важно:
- В заказе может быть несколько товаров.
- Каждый товар может доставляться отдельным продавцом.
- Весь текст, идентифицирующий магазины и партнеров, был заменен названиями великих домов из «Игры престолов».
